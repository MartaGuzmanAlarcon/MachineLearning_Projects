# MachineLearning_Projects
Real-world Machine Learning projects for Healthcare, Finance, and Retail. 

I created this repository as a personal space to practice and learn more Machine Learning by doing.

My goal here isn't just to copy-paste code from tutorials. Instead, I am building these projects to understand better the application and logic behind the algorithms, rather than treating them as black boxes.

I have focused these projects on real-world problems in industries that I found interesting like Biomedical, Finance, and Luxury Retail.

Alongside the code, I am also attaching theoretical and summarized notes and visual cheat sheets. I made them to help me study, but I am sharing them here in case they help anyone else who is learning!
