# MachineLearning_Projects

> **A note before you start:** alongside the code, I have created my own theory notes on the main machine learning algorithms, one page per algorithm with some handwritten annotations. I made them to keep the concepts clear while working on these projects, and I'm sharing them in case they help someone else. You can find them in [`00_ML_Concepts_Cheat_Sheets`](./00_ML_Concepts_Cheat_Sheets).

Real-world Machine Learning projects for Healthcare, Finance, and Retail.

## About this repository

I created this repository as a personal space to practice and learn Machine Learning by doing. The goal is not to copy code from tutorials: I build each project to understand the logic behind the algorithms and where they apply, and not to treat them as black boxes.

The projects focus on real-world problems in industries I find interesting: biomedical, finance and luxury retail.
